# Personal portfolio

Personal portfolio, built with React, TypeScript, and Vite. The site is a static single-page application designed for Cloudflare Pages. Contact is handled through direct email links rather than an in-site form.

## Local development

```sh
npm install
npm run dev
```

The production checks are:

```sh
npm run lint
npm run build
```

## Content updates

Portfolio content lives in `src/content/portfolio.ts`. Project links, skills, social links, and achievement details can be updated there without changing the page layout.
